# تطبيق التنظيم البيداغوجي — 2026-2027

تطبيق Desktop عربي موجّه لمدير المدرسة، مبني بحيث يكون دليل وزارة التربية للسنة 2026-2027 هو Rule Set مستقل وقابل للتحديث.

## ماذا تفعل النسخة الحالية؟
- إدخال معلومات المدرسة.
- المستويات الستة ظاهرة افتراضياً؛ يضيف المدير القسم باختيار المستوى وحرف الشعبة من قائمتين منسدلتين.
- تعريف القاعات واحدةً واحدةً مع نوعها وحالتها وأيام وساعات توفرها، بما في ذلك قاعة التحضيري الاحتياطية.
- إدخال المدرسين يدوياً أو استيراد أسمائهم من ملف Word بصيغة DOCX.
- بطاقة مدرس مبسطة: الاسم، الحجم الأسبوعي، المواد المسموح بها، والأقسام والمواد المسندة فعلياً فقط.
- الإسناد يدوي بالكامل ويبقى محفوظاً مستقلاً عن الجدول المولد؛ لا يغيّره النظام عند إعادة التوليد.
- توليد جدول أوقات آلي مع منع تعارض المدرس والقسم واحترام الأحجام الأسبوعية والحدود اليومية الأساسية.
- تجميع حصص المدرس في أربعة أيام كلما سمحت قواعد توزيع المواد، مع خمسة أيام عمل كحد أقصى للحالات التي تفرض فيها المادة خمسة أيام (مثل رياضيات السنة الأولى أو الثانية).
- الحجم القياسي 18 ساعة يوزع على أربعة أيام: يومان بـ5 ساعات ويومان بـ4 ساعات، ولا يتجاوز المدرس 5 ساعات عمل في اليوم.
- تطبيق قاعدة الفرنسية للسنة الثانية، وتوزيع المواد على الحد الأدنى من الأيام حسب القواعد المفعلة.
- توليد PDF عربي RTL يشمل غلاف المؤسسة، مؤشرات التحقق، المواد المسموح بها، الإسناد، جدول كل قسم، جدول كل مدرس وصفحة المصادقة.
- عرض جدول كل مدرس في شبكة أيام/توقيت ملوّنة تشبه النموذج الإداري المتداول، مع إبراز أيام الراحة.
- عرض الإسناد مجمّعاً حسب المدرّس دون تكرار اسمه، مع المواد والأقسام والحجم المسند والمستهدف والتنبيه إلى النقص.
- بحث وتصفية في المدرسين والإسناد وجدول الحصص، مع واجهة عربية RTL وأعمدة مرتبة من اليمين.
- تدقيق الحمل الإجمالي: إذا كانت طاقة المدرسين أكبر من حجم الأقسام، يشرح النظام استحالة بلوغ 18 ساعة للجميع ويقترح التصحيح دون إنشاء حصص وهمية.
- قاعدة اختبار جاهزة تضم 9 أقسام (منها «أ»، «ب» و«د») و12 مدرساً مؤهلين لكل المواد، مع إسناد وجدول مولّدين؛ يمكن استرجاعها من زر «تحميل بيانات الاختبار».
- كل قواعد 2026-2027 الأساسية موجودة في `config/rules_2026_2027.json` حتى يسهل تعديلها مع Codex دون لمس الواجهة.

## التشغيل
يتطلب Python 3.11+.

```bash
pip install -r requirements.txt
python main.py
```

> Tkinter مدمج عادة مع Python على Windows. إذا لم يكن موجوداً على Linux ثبّت حزمة python3-tk من مدير الحزم.

## الرخصة (Licence)

نظام الرخصة مفعّل: كل نسخة تحتاج كود Ed25519 موقّعاً ومربوطاً بمعرّف جهاز الحريف. المفتاح الخاص يبقى في `keys/license_private.pem` ولا يُوزّع أبداً، بينما يحتوي التطبيق مفتاح التحقق العام فقط. شغّل `python license_generator.py` عندك لإنشاء كود التفعيل بعد أن يرسل لك الحريف معرّف جهازه.

## إنشاء EXE لـ Windows

لإنشاء النسخة النهائية شغّل من PowerShell:

```powershell
.\build_windows.ps1
```

الملف الناتج الذي توزّعه: `dist\TanzimPedagogique.exe`. انسخه كما هو إلى أي Windows 10/11 64-bit؛ لا يحتاج Python. بيانات كل مستخدم تُحفظ بأمان في `%LOCALAPPDATA%\TanzimPedagogique` بدلاً من مجلد التثبيت.

## البنية
- `main.py` نقطة التشغيل.
- `app/db.py` قاعدة SQLite.
- `app/rules.py` تحميل القواعد.
- `app/solver.py` محرك الإسناد والجدولة.
- `app/pdf_export.py` تصدير PDF عربي مدمج بخط Noto Naskh Arabic.
- `app/ui.py` واجهة Desktop.
- `config/rules_2026_2027.json` Rule Set الرسمي القابل للتعديل.
- `app/teacher_import.py` استيراد أسماء المدرسين من ملفات DOCX دون الحاجة إلى Microsoft Word.
- `tests/` اختبارات القواعد والاستيراد والترحيل والإسناد ومنع التعارض.

## ملاحظات تشغيلية
- القواعد الرسمية والأحجام الأسبوعية تبقى في `config/rules_2026_2027.json` ولا تُكتب داخل الواجهة.
- محرك OR-Tools CP-SAT مع التحقق اللاحق يمنع تداخل المدرس والقسم وتجاوز سعة القاعات.
- أيام الراحة هي تفضيلات مرنة (يومان كحد أقصى)، والسبت بعد الظهر تفضيل عام قابل للضبط.
- لا ينشئ النظام حصصاً وهمية لبلوغ 18 ساعة؛ الساعات التكميلية الحقيقية تسجّل بشكل مستقل.
